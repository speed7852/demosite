# ومظلت — موقع خدمات المظلات والسواتر في الرياض

نسخة عرض تجريبية لموقع تعريفي عربي RTL، مبنية باستخدام Next.js، ومهيأة للتصدير الثابت والنشر المجاني على Cloudflare Pages.

## الخدمات المعروضة
- مظلات السيارات
- السواتر
- الخيام وبيوت الشعر
- البرجولات

## التشغيل على الكمبيوتر
المتطلبات: Node.js 20.9 أو أحدث وnpm.

```bash
npm install
npm run dev
```

افتح http://localhost:3000

## فحص نسخة الإنتاج الثابتة
```bash
npm run build
```

سيتم إنشاء الموقع الثابت داخل مجلد `out/`.

## النشر المجاني على Cloudflare Pages عبر GitHub
1. ارفع ملفات هذا المشروع إلى مستودع GitHub جديد. ارفع محتويات المجلد، وليس ملف ZIP نفسه.
2. افتح Cloudflare Dashboard ثم Workers & Pages ثم Create application ثم Pages.
3. اختر Import an existing Git repository واربط حساب GitHub.
4. اختر مستودع `womazallat-saudi`.
5. اختر إعداد Next.js (Static HTML Export)، أو أدخل الإعدادات التالية يدوياً:
   - Production branch: `main`
   - Build command: `npx next build`
   - Build output directory: `out`
6. اضغط Save and Deploy. سيظهر رابط تجريبي مجاني ينتهي بـ `pages.dev`.

## ملاحظات مهمة قبل العرض أو النشر النهائي
1. الاسم التجاري المعروض حالياً هو «ومظلت» كما تم تزويدنا به؛ أكّده مع العميل.
2. رقم واتساب مضبوط حالياً على `966531555682` (يعرض بصيغة +966 53 155 5682). اختبر الرقم مع صاحب النشاط قبل مشاركة الموقع.
3. صور Unsplash الحالية صور إرشادية فقط وليست صور أعمال حقيقية. استبدلها بصور العميل قبل اعتبار المعرض توثيقاً لمشاريعه.
4. لا توجد لوحة تحكم أو قاعدة بيانات أو نموذج طلب محفوظ؛ أزرار التواصل تفتح واتساب/الهاتف.
5. لا تشترِ نطاق `.com` حتى يوافق العميل على التصميم والاسم النهائي. بعد الموافقة يمكن ربط النطاق من Cloudflare Pages > Custom domains.
6. هذه النسخة واجهة عرض أولية وليست مراجعة قانونية أو تحققاً من ادعاءات النشاط.

## طريقة العمل بالذكاء الاصطناعي
افتح مجلد المشروع في محرر مثل VS Code، ثم استخدم ChatGPT لطلب تعديل محدد في كل مرة. بعد كل تعديل شغّل `npm run build`، ثم ارفع التغييرات إلى GitHub؛ سيعيد Cloudflare النشر تلقائياً.
